This repository contains a clean snapshot of its tracked `src/`, `tests/` and `ui/` files and selected build/verification tooling from commit [`9b65247f0f23093ee7147f9c4f80a053a280a07f`](https://github.com/khamirdesai/DAU-Daiict-submission-Sentinel-gujarat-Hackathone/commit/9b65247f0f23093ee7147f9c4f80a053a280a07f). Khamir Desai leads this submission. The project includes shared work, and the submitter has confirmed teammate participation and agreement to reuse it. This repository does not claim sole authorship of shared components or assign an unprovided teammate name. Original Git history remains available upstream.

## Live Sentinel operation

The original application was integrated with Sentinel network video streams. The retained [live-feed findings](https://github.com/khamirdesai/DAU-Daiict-submission-Sentinel-gujarat-Hackathone/blob/9b65247f0f23093ee7147f9c4f80a053a280a07f/docs/LIVE_FEED_FINDINGS.md) report 30/30 RTSP streams active at the end of a staged four-minute run on 2 September 2026. The run delivered 16,913 frames and analysed 1,725 sampled frames. This is simultaneous stream ingest, distinct from full-rate deep-inference coverage.

The 28 September live session produced 4,465 observations and 200 plate reads using four selected deep-inference slots. Its unchanged 5:40 film is the first recording on the public video page. Sentinel serves recorded scenes as simulated-live network streams. The full tour separately uses government footage captured earlier and labelled RECORDED. The government-video poster is an unchanged frame extracted at 45 seconds from the original film.

## Build 2036 packaging

The original `src/`, `ui/`, tools, configuration and README are preserved. This entry adds a labelled deployment wrapper around the original FastAPI application, public demo access through its existing token service, a video page using the original console stylesheet, deployment checks, the adapted 15-slide deck and Frontier 06 pilot proposal. It does not replace the product interface or intercept browser API requests with invented responses.

The public demonstration uses a fresh corpus generated by the original `tools/sandbox/make_media.py` and processed by the original `tools/demo/seed.py --fps 1` on 27 November 2026. The production pipeline produced 261 observations, including 206 observations with plate values. These are processing counts on synthetic footage, not recognition-accuracy scores. Six video cameras and two unmeasured own-feed placeholders are registered. The corpus includes a synthetic multi-camera scenario; it is distinct from the historical government recordings.

`deployment/snapshot/provenance.json` records the snapshot's origin. Previously issued token hashes are removed from the distributed SQLite file. At startup the wrapper relocates local media paths and creates isolated role-scoped demo identities using the original token service. The original authorisation, search, evidence and audit implementations handle application requests. Government ingest, external estate configuration and paid AI providers are disabled in this public sandbox. The public instance operates on the processed corpus; it does not run a new government-grid session or a continuous model worker. Media viewing opens the included local recordings on demand.

Six deployment checks exercise actual API authentication, purpose refusal, administrator refusal, evidence/audit chain verification after relocation, original UI delivery and public integration boundaries. Historical focused verification and the 80,000-row metadata benchmark remain separately dated 26 November.

The 27 November visual deck revision retains the event’s 15-slide template and adds editable workflow, architecture and copilot diagrams, a task-capability heatmap, native charts and enlarged original interface captures. Five additional selected source test modules produced **80 passes, zero skips and zero failures** across zone rules, DEMO/TEST adapters, read-only copilot tools, trace reports and controlled offline operation. See `evidence/additional-capabilities-tests.xml`. These are software checks on controlled inputs, separate from historical recognition audits.

The additional 38-second Sentinel highlights reel uses four excerpted sections of the original narrated government film (0–9, 80–89, 186–195 and 268–275 seconds), followed by a new dated end card. The full 5:40 film remains available unchanged and is the default recording.

## Distribution boundaries

No original government runtime database, credentials, private government endpoints, model weights or raw government footage dataset is included. The distributed database and six newly generated camera files belong only to the synthetic corpus. Previously public demonstration films are reproduced as submission evidence. The video page has no external analytics. The original application writes queries and case actions into its synthetic sandbox and audit log; this demonstration state can reset when the service restarts. Do not enter personal or real case data. Source licensing is not changed. The video page reuses the original system-font console styling. Third-party model/tool licenses remain separate.
