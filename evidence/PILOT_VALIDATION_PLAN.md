# Proposed Indore pilot and evaluation

Status: **proposal, not an approved or completed pilot.** The objective is to establish whether SAAKSHYA helps an authorized investigator find and review vehicle sightings on a small, representative camera cluster without obscuring uncertainty.

## Before an operational pilot

1. Agree with the camera owner on access, lawful purpose, retention and who may review images. Do not connect the public synthetic demo to operational feeds.
2. Select a small set of cameras across different lighting, angles and traffic density. Record which feeds are unsuitable for plate reading and why.
3. Create a labeled reference set from authorized footage. Include cases with no matching vehicle, obscured plates, difficult light and broken camera timebases. Reserve cameras or time periods for evaluation before tuning.
4. Define the reference unit in advance: one vehicle passage at one camera, with a plate only when a reviewer can read it and a time window for the passage. Have a second reviewer adjudicate disputed labels where feasible.

## Measure against an explicit baseline

Compare the standard manual review process with a SAAKSHYA-assisted workflow using the same authorized case scenarios. Record scenario difficulty and the time to find, check and document each candidate. Randomize or counterbalance the order where practical, and use separate scenarios when a reviewer would otherwise remember an answer.

Report the number of cases and, separately, number of vehicle passages; matched passages, misses, and incorrect or unsupported candidates; precision and recall with uncertainty appropriate to the sample; review time including verification; and how often evidence records retain and verify the media rather than metadata alone. Track by camera and viewing condition, and report excluded or unreadable items. The existing synthetic snapshot check is a retrospective development-set result, not the baseline for a real pilot.

An operator must review every proposed match. A route is not treated as a timed journey unless the relevant camera clocks are adequately established. A small pilot will expose failure modes; it cannot establish statewide accuracy, legal admissibility or production security on its own.
